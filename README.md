# Dionysus

A custom Arch Linux + Hyprland desktop configuration and dotfiles collection for a sleek, neon-styled workstation setup.

This repository contains the configuration files, scripts, and themes that power the Dionysus desktop environment, including Hyprland, Waybar, EWW widgets, Rofi, Cava, Firefox styling, Alacritty, and a custom Neofetch setup.

![Dionysus Demo](https://raw.githubusercontent.com/pewdiepie-archdaemon/dionysus/dionysus/assets/demo.gif)

## Highlights

- Hyprland window manager configuration with custom behavior and workflow tweaks
- Waybar + EWW widgets for system monitoring and desktop HUD
- Rofi launcher and power menu customization
- Terminal and shell configuration for a modern CLI experience
- Animated Neofetch and Cava visualizer integrations
- Custom Firefox theme and laptop-specific performance tools
- ASUS keyboard helpers and custom scripts for laptop tuning
